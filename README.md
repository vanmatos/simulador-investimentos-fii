# 📊 Simulador de Investimentos e Alocação de Portfólio — Excel

## Sobre o projeto

Exercício prático desenvolvido durante um curso de Excel para aplicar fórmulas, funções financeiras, busca de dados e parametrização de cálculos.

A ferramenta permite simular a evolução de investimentos mensais e distribuir o aporte entre diferentes tipos de FIIs de acordo com o perfil de investimento selecionado.

## 🔎 Funcionalidades

* Cálculo automático da sugestão de aporte a partir da renda.
* Projeção do patrimônio para **2, 5, 10, 20 e 30 anos**.
* Estimativa de dividendos mensais.
* Seleção de perfil: **Conservador, Moderado e Arrojado**.
* Distribuição automática do aporte entre categorias de FIIs.
* Consulta de percentuais utilizando **PROCV** e uma base de apoio.

## 🛠️ Recursos de Excel utilizados

* **VF (Valor Futuro)** — projeção do patrimônio.
* **PROCV** — busca dos percentuais de distribuição.
* **SOMA** — consolidação dos valores.
* **Validação de Dados** — seleção do perfil.
* **Intervalos Nomeados** — organização e legibilidade das fórmulas.
* **Referências absolutas e relativas**.
* **Concatenação de dados** para criação da chave de consulta.
* Formatação de valores monetários e percentuais.

## 🗂️ Estrutura

**APP_Invest:** interface principal, parâmetros, cálculos e resultados.

**Planilha_Apoio:** base de referência utilizada na distribuição dos percentuais por perfil e tipo de FII.

## 📚 Aprendizado

Projeto inicial desenvolvido para consolidar conhecimentos de Excel e servir como base para estudos posteriores em **Power Query, Power BI e análise de dados**.

**Obs:** Projeto educacional. Os resultados são provenientes de uma simulação e não constituem recomendação de investimento.
